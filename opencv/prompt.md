## OpenCV 정리 기준

- 설치 관련 내용은 사용자가 요청하지 않으면 수정하지 않는다.
- 이미지 처리 개념은 `pixel`, `channel`, `shape`, `dtype`, `BGR/RGB`, `grayscale`, `sampling`, `quantization`처럼 실습에서 확인할 수 있는 값과 연결한다.
- Python OpenCV는 보통 `cv2`와 `numpy.ndarray`를 같이 사용한다는 점을 적는다.
- C/C++ 개념과 연결되면 짧게 비교한다.
- OpenCV는 컬러 이미지를 기본적으로 BGR 순서로 다루는 경우가 많으므로 RGB와 헷갈리지 않게 적는다.
- `cv2.imread()`가 실패하면 `None`을 반환할 수 있으므로 파일 경로 확인 내용을 적는다.
- 확실하지 않은 내용은 단정하지 말고 "보통은", "환경에 따라", "확인 필요"처럼 표시한다.
- 공식 문서나 현재 실습 환경과 맞지 않는 내용은 팩트체크해서 고친다.
- 이미 앞에서 정리한 내용과 중복되면 반복은 줄이고 이번 수업에서 새로 필요한 부분만 적는다.

## 실제 예시 1: 이미지 읽기

````markdown
## 이미지 읽기

OpenCV에서는 이미지를 읽을 때 `cv2.imread()`를 사용한다.

```python
import cv2

img = cv2.imread("test.png")
print(type(img))
print(img.shape)
print(img.dtype)
```

확인한 점:
- 이미지는 보통 `numpy.ndarray`로 들어온다
- `shape`로 이미지 크기와 channel 수를 확인할 수 있다
- `dtype`은 보통 `uint8`이 많이 나온다

주의할 점:
- 파일 경로가 틀리면 `img`가 `None`일 수 있다
- 바로 `img.shape`를 찍으면 에러가 날 수 있으니 `img is None`을 먼저 확인하는 것이 좋다
````

## 실제 예시 2: BGR/RGB

````markdown
## BGR과 RGB

일반적으로 색은 RGB 순서로 설명하지만 OpenCV는 기본적으로 BGR 순서를 많이 사용한다.

```python
img = cv2.imread("test.png")
rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
```

정리:
- OpenCV에서 읽은 컬러 이미지는 BGR 순서로 생각한다
- matplotlib이나 PIL 같은 library로 넘길 때는 RGB 변환이 필요할 수 있다
- 색이 이상하게 보이면 channel 순서를 먼저 의심한다
````
