# 멀티모달 AI 기반 스마트 교차로 교통상황 분석 및 신호제어 의사결정 지원 대시보드

## 1. 프로젝트 개요

본 프로젝트는 스마트시티 교차로에서 발생하는 차량 흐름, 보행자 대기, 긴급차량 접근, 정체 및 사고 의심 이벤트를 Vision AI와 생성형 AI로 분석하고, 웹 기반 디지털 트윈 대시보드에서 교통상황을 시각화하는 프로토타입을 구현하는 것을 목표로 한다.

초기 단계에서는 실제 도로 신호기와 직접 연결하지 않고, 샘플 영상, 이미지, 시뮬레이션 데이터, 가상 센서 데이터를 기반으로 교차로 상태를 분석한다. 분석 결과는 교통 이벤트로 저장하며, AI Agent가 현재 상황을 요약하고 신호 전환 또는 우선 제어 시나리오를 추천한다.

제안서의 핵심 방향인 `Vision AI`, `VLM`, `LLM`, `RAG`, `AI Agent`, `자연어 기반 인터페이스`, `공공데이터 연계`, `웹 서비스 프로토타입`을 반영하여, 공공 CCTV 영상분석 기술을 스마트 교차로 교통관리 서비스로 확장한 형태로 기획한다.

## 2. 프로젝트명

**멀티모달 AI 기반 스마트 교차로 교통상황 분석 및 신호제어 의사결정 지원 대시보드**

대안 프로젝트명:

- **VLM·LLM 기반 스마트 교차로 혼잡 분석 및 디지털 트윈 신호제어 시뮬레이션**
- **AI 기반 스마트시티 교통상황 분석 및 신호제어 추천 대시보드**

## 3. 제안 배경

도심 교차로에서는 시간대별 차량 흐름, 보행자 대기, 긴급차량 접근, 사고 의심 상황이 복합적으로 발생한다. 기존 고정 신호 방식이나 단순 관제 방식은 현장 상황 변화에 즉각적으로 대응하기 어렵고, 운영자가 모든 CCTV 화면과 이벤트를 실시간으로 확인하기에도 부담이 크다.

최근 Vision AI, VLM, LLM, RAG 기술이 발전하면서 CCTV 영상과 교통 이벤트 데이터를 분석하고, 사용자가 자연어로 상황을 질의하며, AI가 의사결정에 필요한 정보를 요약하는 서비스 구조가 가능해지고 있다.

다만 8주 프로젝트 범위에서 실제 신호기를 자동 제어하거나 현장 CCTV, 신호제어기, 긴급차량 통신망과 직접 연동하는 것은 현실적으로 부담이 크다. 따라서 본 프로젝트는 실제 인프라 제어가 아니라, 시뮬레이션 환경에서 교통상황을 분석하고 신호제어 의사결정을 지원하는 프로토타입으로 범위를 설정한다.

## 4. 프로젝트 목표

교차로 영상 또는 시뮬레이션 데이터를 AI가 분석하여 차량, 보행자, 긴급차량, 정체 상황을 감지하고, 사용자가 웹 대시보드와 자연어 질의를 통해 현재 교통상황과 추천 조치를 확인할 수 있는 프로토타입을 구현한다.

이를 통해 다음 흐름을 검증한다.

1. 교차로 영상, 이미지 또는 시뮬레이션 데이터 입력
2. Vision AI/VLM 기반 차량, 보행자, 정체, 긴급차량 상황 분석
3. 교통 이벤트 생성 및 저장
4. 디지털 트윈 대시보드에서 교차로 상태 시각화
5. AI Agent 기반 신호제어 시나리오 추천
6. 자연어 질의응답, 이벤트 요약, 보고서 생성

## 5. 주요 기능

### 5.1 교차로 영상 및 시뮬레이션 분석

교차로 CCTV 프레임, 샘플 영상, 이미지 또는 시뮬레이션 화면을 입력받아 차량, 보행자, 차선, 신호등, 긴급차량, 정체 상황을 분석한다.

예시 기능:

- 차량 객체 탐지
- 방향별 차량 수 및 대기열 추정
- 보행자 대기 또는 횡단 요청 상태 감지
- 긴급차량 접근 이벤트 감지 또는 시뮬레이션
- 교차로 내부 정체 및 비정상 정지 상황 감지
- VLM 기반 교차로 장면 설명 생성

### 5.2 교통 이벤트 감지 및 관리

영상 분석 결과를 단순 화면 표시로 끝내지 않고 교통 이벤트 데이터로 저장한다.

예시 이벤트:

- 북쪽 방향 차량 대기열 기준치 초과
- 동쪽 방향 긴급차량 접근
- 보행자 횡단 요청 발생
- 신호 전환 후 대기열 감소 미흡
- 교차로 내부 차량 잔류
- 특정 차선 장시간 정지

저장 항목 예:

- 이벤트 ID
- 발생 시각
- 발생 방향
- 이벤트 유형
- 심각도
- 관련 객체 수
- AI 분석 요약
- 추천 조치
- 처리 상태

### 5.3 신호제어 의사결정 지원

AI Agent는 이벤트 우선순위와 현재 교통상황을 종합해 신호제어 시나리오를 추천한다.

추천 예시:

- 북남 방향 녹색 신호 10초 연장
- 동서 방향 대기열 증가로 다음 주기 우선 배정
- 긴급차량 접근으로 동쪽 방향 우선 신호 적용
- 보행자 대기 시간이 기준치를 초과하여 횡단 신호 삽입
- 교차로 내부 잔류 차량으로 전체 적색 안전 단계 적용

초기 프로토타입에서는 실제 신호 제어 명령이 아니라, `추천` 또는 `시뮬레이션 적용`으로 표현한다.

### 5.4 자연어 질의 인터페이스

사용자가 복잡한 메뉴를 조작하지 않아도 자연어로 교통상황을 조회할 수 있도록 한다.

예시 질문:

- "현재 가장 혼잡한 방향은 어디야?"
- "지난 10분 동안 평균 대기 시간이 얼마나 변했어?"
- "긴급차량 우선 신호는 언제 실행됐어?"
- "보행자 요청이 가장 많았던 시간대를 알려줘."
- "현재 교차로 위험 요인을 요약해줘."
- "고정 신호 방식과 비교했을 때 어떤 개선이 있었어?"

### 5.5 웹 디지털 트윈 대시보드

사용자는 웹 대시보드에서 교차로 상태와 AI 분석 결과를 확인한다.

대시보드 구성:

- 교차로 디지털 트윈 시각화
- 방향별 차량 대기열
- 현재 신호 단계
- 보행자 요청 상태
- 긴급차량 우선 제어 상태
- 교통 이벤트 타임라인
- 평균 대기 시간 및 혼잡도 지표
- AI 요약 카드
- 자연어 질의 채팅창
- 시뮬레이션 제어 패널

### 5.6 보고서 생성

LLM을 활용해 일정 시간 동안의 이벤트와 제어 추천 결과를 요약한 리포트를 생성한다.

보고서 예시:

- 10분 단위 교통상황 요약
- 긴급차량 우선 처리 이력
- 보행자 요청 처리 현황
- 혼잡 방향 변화 분석
- 고정 신호 대비 개선 효과
- 이상 이벤트 및 후속 조치 제안

## 6. AI 활용 방향

### 6.1 VLM

`VLM`은 이미지 또는 영상 프레임을 이해하고, 교차로 장면 안의 차량, 보행자, 차선, 신호 상태, 위험 상황을 설명하는 데 활용한다.

활용 예:

- "북쪽 방향 차량 대기열이 길게 형성되어 있습니다."
- "동쪽 차선에서 긴급차량으로 보이는 객체가 접근하고 있습니다."
- "횡단보도 앞에 보행자가 대기 중입니다."

### 6.2 LLM

`LLM`은 사용자의 자연어 질문을 이해하고, 이벤트 로그와 분석 결과를 바탕으로 답변을 생성한다.

활용 예:

- 교통 이벤트 요약
- 현재 혼잡 상황 설명
- 사용자 질문 응답
- 시간대별 리포트 생성
- 신호제어 추천 이유 설명

### 6.3 RAG

`RAG`는 저장된 교통 이벤트 로그, 신호 전환 이력, 가상 센서 데이터, 운영 기준 문서, 공공데이터 기반 통계 자료 등을 검색하여 답변의 근거를 보강하는 데 활용한다.

활용 예:

- 과거 이벤트 기반 질의응답
- 운영 기준 문서 기반 신호 추천 근거 제시
- 공공데이터 기반 교통 패턴 참고
- 교통 리포트와 요약 이력 검색

### 6.4 AI Agent

`AI Agent`는 분석, 검색, 요약, 신호제어 추천 기능을 연결하여 사용자의 요청을 단계적으로 처리한다.

예시:

사용자: "현재 위험한 상황을 요약하고, 다음 신호 주기 추천안을 알려줘."

AI Agent 처리 흐름:

1. 최근 교통 이벤트 로그 검색
2. 혼잡도, 보행자 요청, 긴급차량 이벤트 필터링
3. 현재 교차로 위험 요인 요약
4. 신호제어 후보 시나리오 생성
5. 추천 이유와 예상 효과 설명
6. 대시보드에 처리 결과 표시

## 7. 기술 스택 제안

### 7.1 Frontend

**Next.js + React + TypeScript**

역할:

- 웹 디지털 트윈 대시보드 구현
- 교차로 분석 결과 화면 표시
- 이벤트 타임라인 UI 구현
- 자연어 질의 채팅 UI 구현
- 신호제어 시뮬레이션 UI 구현
- 혼잡도 통계 및 리포트 화면 구현

선정 이유:

- React 기반 대시보드 UI 개발에 적합
- 상태 변화, 차트, 타임라인, 채팅 화면 구현이 용이
- TypeScript를 통해 컴포넌트와 API 응답 타입을 명확히 관리 가능

### 7.2 Backend

**FastAPI**

역할:

- 영상 및 이미지 업로드 API
- AI 분석 요청 API
- 자연어 질의 API
- 교통 이벤트 로그 조회 API
- 신호제어 추천 API
- WebSocket 기반 실시간 이벤트 알림 API

선정 이유:

- Python 기반이므로 AI 및 영상처리 라이브러리와 연동이 쉽다.
- `OpenCV`, `YOLO`, `VLM`, `LLM`, `RAG` 파이프라인을 같은 언어 환경에서 구성하기 좋다.
- API 문서 자동 생성이 가능하여 팀 개발과 멘토 검토에 유리하다.

### 7.3 Vision AI

**OpenCV + YOLO 계열 모델 + VLM**

역할:

- `OpenCV`: 영상 프레임 추출 및 전처리
- `YOLO`: 차량, 보행자, 신호등 등 객체 탐지
- `VLM`: 장면 이해, 위험 상황 설명, 교통상황 판단 보조

### 7.4 Database

**PostgreSQL + Vector DB**

역할:

- `PostgreSQL`: 이벤트 로그, 신호 상태, 분석 결과, 사용자 질의 이력 저장
- `pgvector` 또는 `ChromaDB`: 이벤트 설명, 운영 문서, 요약 정보의 임베딩 검색

저장 데이터 예:

- 이벤트 발생 시간
- 발생 방향 및 위치
- 감지 객체
- 혼잡도 점수
- 신호 상태
- AI 요약 결과
- 추천 조치
- 사용자 질문 및 답변 이력

### 7.5 Realtime / Simulation

**WebSocket + 교통 시뮬레이터**

역할:

- `WebSocket`: 대시보드 실시간 이벤트 알림
- 교통 시뮬레이터: 차량 흐름, 보행자 요청, 신호 전환 결과 시뮬레이션

초기 구현에서는 실제 신호기와 직접 연동하지 않고, 가상 교차로 데이터와 시뮬레이션 상태를 사용하여 신호 전환, 대기열 변화, 긴급차량 우선 처리 등을 검증한다.

### 7.6 Deployment

**Docker**

역할:

- Frontend, Backend, Database, AI Worker를 컨테이너로 분리
- 팀원 간 동일한 실행 환경 구성
- 향후 배포 및 확장 용이

## 8. 시스템 아키텍처

```text
샘플 영상 / 이미지 / 교통 시뮬레이션 데이터
        ↓
FastAPI Backend
        ↓
OpenCV 프레임 추출 및 전처리
        ↓
YOLO / VLM 교통상황 분석
        ↓
교통 이벤트 생성
        ↓
PostgreSQL / Vector DB 저장
        ↓
LLM / RAG 자연어 질의응답
        ↓
AI Agent 신호제어 추천
        ↓
Next.js 디지털 트윈 대시보드
        ↓
이벤트 알림 / 보고서 / 신호제어 시뮬레이션
```

## 9. MVP 구현 범위

8주 프로젝트 기준으로 실제 교통 인프라와 연동하는 완성형 서비스보다, 핵심 흐름이 동작하는 프로토타입을 목표로 한다.

### 1차 MVP

- 샘플 이미지 또는 짧은 교차로 영상 업로드
- 차량/보행자 객체 탐지 또는 샘플 분석 결과 표시
- 방향별 차량 수, 대기열, 혼잡도 계산
- 교통 이벤트 더미 또는 간단한 규칙 기반 생성
- 이벤트 목록과 교차로 상태 대시보드 표시
- 신호 상태 및 신호 전환 시뮬레이션

### 2차 MVP

- 자연어 질의응답 기능 추가
- 이벤트 로그 기반 요약 답변 생성
- RAG 기반 운영 기준 또는 공공데이터 검색
- AI Agent 기반 신호제어 추천 메시지 생성

## 12. 제안서와의 정합성

본 아이디어는 제안서의 다음 요소와 연결된다.

- `공공 CCTV 영상분석`: 교차로 CCTV 기반 교통상황 분석으로 반영
- `Vision AI`: 차량, 보행자, 정체, 위험 상황 분석 기능으로 반영
- `VLM`: 교차로 장면 이해 및 상황 설명에 활용
- `LLM`: 자연어 질의응답, 요약, 보고서 생성에 활용
- `RAG`: 이벤트 로그, 운영 문서, 공공데이터 기반 답변 보강에 활용
- `AI Agent`: 분석, 요약, 신호제어 추천을 연결하는 자동화 흐름에 활용
- `공공데이터 연계`: 교통 통계, 사고 데이터, 도로 운영 기준 등을 검색 근거로 활용
- `UI/UX 설계`: 디지털 트윈 대시보드와 자연어 질의 화면으로 구현
- `기능별 프로토타입`: 영상 분석, 질의응답, 신호제어 시뮬레이션으로 구현

## 13. 한 줄 요약

교차로 영상과 시뮬레이션 데이터를 AI가 분석해 혼잡, 보행자, 긴급차량, 위험 이벤트를 감지하고, 사용자가 자연어로 상황을 확인하며 신호제어 추천안을 검토할 수 있는 멀티모달 AI 스마트 교통 대시보드이다.
